# Überform

**Become your next form.**

Überform is a dark, premium fitness dashboard designed to help users track their workouts, monitor progress, and stay consistent with their fitness goals.

## Features

- **Dashboard** — an overview of workout activity, statistics, and weekly progress.
- **Workout Tracking** — log workouts and review training history.
- **Activity Calendar** — keep track of completed training sessions.
- **Statistics & Achievements** — monitor progress and celebrate consistency.
- **Customizable Appearance** — choose an accent color to personalize the interface.
- **Settings & Privacy** — manage preferences, export application data, clear workout history, or delete locally stored data.
- **Responsive Design** — an interface adapted for desktop, tablet, and mobile screens.

## Built With

- React
- Vite
- JavaScript
- CSS

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   
   git clone https://github.com/andreamartinic/uberform.git
   

2. Navigate to the project directory:

   
   cd uberform
   

3. Install dependencies:

   
   npm install
   

4. Start the development server:

   
   npm run dev
   

5. Open the local URL displayed in your terminal.

### Production Build

To create a production build, run:


npm run build
